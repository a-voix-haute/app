CONTRIBUTIONS

  Les propositions d'amélioration sont bienvenues, sous forme de « pull
  request » sur https://github.com/a-voix-haute/app

  Quelques attentes, qui valent pour les échanges autant que pour le code :

    Décrivez le problème que votre modification résout, et pourquoi cette
    solution plutôt qu'une autre.

    Suivez les conventions du projet : tout est rédigé en français, code,
    commentaires et messages de commit compris.

    Vérifiez que les tests passent avant de proposer.

    Restez courtois. Un désaccord technique se discute ; une contribution
    refusée n'est pas un jugement sur son auteur.

  cette même licence.
